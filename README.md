# 🪐 Cosmos Singularity

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

**Cosmos-Singularity** is an orbital-grade project creator and developer scaffolding engine. It bridges raw CLI generator power with a sleek desktop GUI, condensing language selection, framework options, build tooling, and boilerplate configuration into a single point of ignition.

---

## ✨ Features

- **⚡ Visual Stack Matrix:** Select primary languages (TypeScript, Node.js, Rust, Go, Python, C#, etc.) and instantly pair them with compatible frameworks and build pipelines.
- **🖥️ GUI-Powered CLI Engine:** Seamlessly wrap low-level CLI initializers (e.g., `create-next-app`, `vite`, `cargo new`, `dotnet new`) into an intuitive interactive dashboard.
- **🎛️ Preset & Template Foundry:** Save custom workspace configurations, preset flags, and repository structures for instant reuse across future projects.
- **🗂️ Workspace & Git Scaffolding:** Automatically initialize target directories, configure `.gitignore` rules, initialize local `.git` repositories, and run baseline `npm install` / dependency cycles.
- **🔌 Configurable Execution Rules:** Define custom template sources, JSON-based generator blueprints, and shell execution paths without modifying core app source.

---

## 🚀 Tech Stack

- **Desktop Shell:** Electron
- **Language:** TypeScript
- **Frontend:** React + Vite
- **Styling:** Tailwind CSS
- **Integration Layer:** Node.js Process Spawner / System CLI Execution
